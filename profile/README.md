# Embedded Systems SHSU

Welcome to the GitHub organization for our embedded systems team project at Sam Houston State University (SHSU).

We're Team 4 in **COSC 4347: Embedded System Design and IoT (Fall 2026)**. This organization is where we collaborate on code, track our progress, and keep project documentation in one place.

## Repository Visibility

Our project repositories will stay **private during the semester**, at least until the relevant project deadlines have passed. After that, we may make them public if the team agrees and the materials are appropriate to share.

## Current Project

**Encrypted Occupancy Counter:** An embedded system that counts people entering and leaving a space using sensors, microcontrollers, and wireless communication.
